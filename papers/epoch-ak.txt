New bounds for arithmetic Kakeya
A Kakeya set in Rd is a bounded set which contains a unit line segment in every direction. While such sets can have
measure zero, the Kakeya conjecture posits that they always have the maximal possible (Minkowski and Hausdor!)
dimension d. This conjecture was proved for d = 2 by Davies [2] and in a recent breakthrough for d = 3 by Wang
and Zahl [10], but remains open for d → 4.
    The arithmetic Kakeya conjecture was implicitly formulated by Katz and Tao [7], as a statement strong enough to
imply (a form of) the Kakeya conjecture, but which can be formulated as a purely additive combinatorics statement,
rather than harmonic analysis. The meta-theory of the arithmetic Kakeya conjecture was developed by Green and
Ruzsa [4], who gave a number of equivalent formulations.
    One way to state the arithmetic Kakeya problem is the following: we say that AK(ω) holds if for any ε > 0 there
exists a constant Cω > 0 and a finite set X ↑ Z2 such that r1 + r2 ↓= 0 for all x ↔ X, and for all finite G ↑ Z2 ,

                                            |(1, ↗1) · G| ↘ Cω max|x · G|ε+ω ,
                                                                 x→X

where
                                          x · G = {x1 g1 + x2 g2 : (g1 , g2 ) ↔ G}.
Note that we are not interested in the size or nature of X itself – for the applications to the Kakeya conjecture itself,
all that matters is the exponent ω.
    It is trivial that AK(2) holds (for example by taking X to be any two linearly independent vectors in Z2 , as
then (1, ↗1) can be expressed as a linear combination of these two). The arithmetic Kakeya conjecture itself is the
following.
Conjecture 1 (Arithmetic Kakeya conjecture). AK(1) holds.
    The first non-trivial bound was obtained by Bourgain [1], who proved AK( 25    13 ). Katz and Tao improved this, first
in [6] to AK( 74 ), and then later [7] to AK(ϑ) where ϑ = 1.6751308 · · · is the largest root of x3 ↗ 4x + 2 = 0.
    The relation to the Kakeya problem is the following.
Theorem 1. If AK(ω) holds then, for all d → 2, if E ≃ Rd is a Kakeya set (a bounded set containing a unit line
segment in every direction) then the Hausdor! dimension of E is at least

                                                     ω↑1 d + 1 ↗ ω↑1 .

    This was implicitly established by Bourgain [1] using the ‘method of slices’, although Bourgain only established
this for the Minkowski dimension. The stronger statement that this same bound holds for the Hausdor! dimension
is a consequence of combining Bourgain’s argument with recent progress on Szemerédi’s theorem by Leng, Sah, and
Sawhney [9].
    The arguments of Katz and Tao [6] are very concrete, and proceed by finding explicit small graphs with certain
properties. The goal of this problem is to find other explicit small graphs which lead, via the same argument, to
better bounds.
    Most optimistically, one could hope for finding a construction that establishes AK(ω) for some ω < 1.67 · · · . This
would immediately, via the above, improve the known lower bounds for the Kakeya conjecture in all su”ciently high
dimensions.
    Any new constructions would be of interest, however, as the argument of Katz and Tao [6] that produces the
current limit of ω = 1.6751308 · · · requires an extremely large set of dilates X (that increases without bound as

The problem proposal
We will first explicitly define the kind of structure that is required, and how to ‘score’ such a structure (i.e. what
value of ω a structure would prove AK(ω) for). We will then give, in this language, two examples of Katz and Tao.
In the following subsection we sketch briefly how the proof goes, using the argument of Katz and Tao [6]. In this
subsection we have presented things to be clear for the human reader; an equivalent, but more opaque, version which
is more suitable for Python verification is given in Appendix ??.
    We first define a collection of constructible configurations iteratively.
Definition 1. Let X ↑ Z2 . An X-constructible graph is a (simple undirected) finite graph, in which each edge is
labelled with some v ↔ X, defined in the following iterative fashion.
  1. A single vertex is constructible.
  2. If H is constructible then, for any integer k → 1, if X1 , . . . , Xk are sets of vertices of H, then the following
     graph is constructible: take k + 1 disjoint copies of H and then, for each 1 ↘ i ↘ k and x ↔ Xi , either identify
     the vertices corresponding to x in both Hi↑1 and Hi , or put an edge between them labelled with some v ↔ X.

Given a finite set V , for any g ↔ V and x ↔ Z2 we write xg for the 2 ⇐ |V | matrix which is zero everywhere except
in the column corresponding to g, in which it is the column vector x.
Definition 2. Let G be a finite graph with vertex set V , such that each edge is labelled with some x ↔ Z2 . An
X-forcing pair for G is a pair of sets (R, T ) with T ≃ V and R a finite collection of 2 ⇐ |V | integer matrices, with
columns indexed by g ↔ V , such that
                                            R ≃ {xg : x ↔ X and g ↔ V },
and such that a finite sequence of the following operations on (R, T ) eventually produces T = V :
  1. If g1 ⇒ g2 is an edge of G labelled v then add vg1 ↗ vg2 to R.
  2. If (1, ↗1)g ↔ R then add g to T .
  3. Any Z-linear combination of matrices in R can be added to R.
   Informally speaking, the idea is that knowledge of x·g for xg ↔ R, together with knowledge of all h ↔ T , is enough,
when combined with the identifications encoded in the edges of G and the injectivity of the map g ⇑⇓ (1, ↗1) · g, to
know the values of all vertices of G.

   In the following subsection we sketch how, as the terminology suggests, a constructible proof of ω(X) ↘ ω implies
the arithmetic Kakeya statement AK(ω).
Goal 1 (New bounds for the arithmetic Kakeya conjecture). Find a finite X ↑ Z2 \⇔(1, ↗1)↖ together with a con-
structible proof of
                                           ω(X) < 1.67513 · · · ,
where the right-hand side is more precisely the largest root of x3 ↗ 4x + 2 = 0. More ambitiously, can this be done
for some ω close to 3/2?
   We reiterate that finding any X for which ω(X) < 1.67513 · · · would already improve the current best bound
known for the arithmetic Kakeya conjecture, and hence also improve the known lower bounds for the Kakeya
conjecture in high dimensions.
   A simple case of particular interest is when X = {(1, 0), (0, 1), (1, 1)} (although this has no direct applications, that
we are aware of, to other problems such as Kakeya). This special case is sometimes referred as the Sums-Di!erences
conjecture. The current best-known upper bound of

                                              ω({(1, 0), (0, 1), (1, 1)}) ↘ 11/6

is due to Katz and Tao [6].

Goal 2 (New bounds for the Sums-Di!erences conjecture). Find a constructible proof of

                                             ω({(1, 0), (0, 1), (1, 1)}) < 11/6.

   The current best-known lower bound for such an ω is ω → 1.77898, proved by Lemm [8] (with very slight further
improvements found by AlphaEvolve [3]).
   We will now give, in this language, two examples of constructible proofs, both adapted from Katz and Tao [6].
The first is a constructible proof of
                                         ω({(1, 0), (0, 1), (1, 1)}) ↘ 11/6.
The second achieves an improved upper bound of ↘ 7/4, but at the cost of adding a new dilate (1, 2) to X.

The link to arithmetic Kakeya
In this subsection we sketch how a ‘constructible proof’ as defined in the previous subsection actually implies a bound
for the arithmetic Kakeya problem. We fix a finite set G ↑ Z2 such that |x · G| ↘ N for all x ↔ X. We seek an
upper bound on |(1, ↗1) · G|. Without loss of generality we can assume that g ⇑⇓ (1, ↗1) · g is injective, whence it
su”ces to simply give an upper bound on |G| itself.
    An X-constructible graph H is to be interpreted as a subset H ≃ G such that if there is an edge between h1 and
h2 labelled x then we have x · h1 = x · h2 .
    The goal is to find lower and upper bounds for the number of such H that appear as subsets of G, and then
comparing these give the required upper bound on |G|. For the lower bound, we use the following lemma (which
appears as [6, Lemma 2.1]).
